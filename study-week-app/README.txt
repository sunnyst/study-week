STUDY WEEK — LOCAL APP

No install or account is needed. Python 3 is only needed if you want to run the local server.

Mac:
1. Unzip this folder somewhere convenient.
2. Double-click start.command.
3. If macOS blocks it, right-click start.command > Open.
4. Keep the Terminal window open and visit http://localhost:8000 in your browser.
5. To stop the server, focus Terminal and press Control-C.

Alternative:
Open index.html directly in your browser. Browser local storage behavior for file:// pages can vary, so the local server method is recommended.

Your study entries and weekly goal are stored in this browser's local storage on this device only.
They are not synced to other devices. Clearing browser site data may erase them.
No example entries are preloaded. The chart starts empty.
